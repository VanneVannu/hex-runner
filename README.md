# HEX RUNNER

Juego arcade de infiltración en memoria inspirado en Pac-Man, desarrollado con HTML5 Canvas, CSS y JavaScript puro (Web Audio API).

## Mecánicas
- **Extracción de Bytes:** Recorre los sectores de memoria recolectando datos sin ser interceptado.
- **Zero-Day Exploits:** Nodos rojos en las esquinas que invierten la seguridad del sistema y permiten eliminar temporalmente a los antivirus.
- **4 Algoritmos de Antivirus:**
  - `FIREWALL`: Persecución directa.
  - `SCANNER`: Predice tu trayectoria para emboscarte.
  - `TRACER`: Patrullaje errático por sectores.
  - `QUARANTINE`: Mantiene distancia táctica.

## Controles
- **Flechas direccionales** o **W A S D** para moverse por la cuadrícula.
